# 施設警備2級 超問題集

iPhoneからGitHubへアップロードしやすいように、必要ファイルをすべて同じ階層へ配置した静的Webアプリです。

## 公開方法

1. ZIPを解凍します。
2. 解凍したフォルダ内の9ファイルをすべてリポジトリへアップロードします。
3. 同名ファイルの上書き確認が表示された場合は、そのまま上書きします。
4. リポジトリの「Settings」→「Pages」を開きます。
5. Sourceを「Deploy from a branch」、Branchを「main」、フォルダを「/(root)」にして保存します。

`index.html`、`app.js`、`app.css`、各アイコンなど、9ファイルすべてがリポジトリ直下に並んでいれば正常です。
