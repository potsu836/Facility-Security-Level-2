# 施設警備2級 特別講習対策

iPhoneからGitHubへアップロードしやすいように、必要ファイルをすべて同じ階層へ配置した静的Webアプリです。全650問を5択形式で収録し、特別講習向けの4分野構成に合わせています。

## 主な変更点（v2.0）

- 全650問を5択形式へ統一
- 4分野（基本的事項・関係法令・保安業務・応急措置）へ再編
- 模擬試験20問を3問・6問・7問・4問の比率で出題
- 誤った表現と正しい内容を対比する解説へ変更
- 添付教材や実際の試験問題を転載せず、オリジナル問題として構成
- v2.1で黒画面になる描画エラーを修正

## 公開方法

1. ZIPを解凍します。
2. 解凍したフォルダ内の9ファイルをすべてリポジトリへアップロードします。
3. 同名ファイルの上書き確認が表示された場合は、そのまま上書きします。
4. リポジトリの「Settings」→「Pages」を開きます。
5. Sourceを「Deploy from a branch」、Branchを「main」、フォルダを「/(root)」にして保存します。

`index.html`、`app.js`、`app.css`、各アイコンなど、9ファイルすべてがリポジトリ直下に並んでいれば正常です。
